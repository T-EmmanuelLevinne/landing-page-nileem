LANDING PAGE PROJECT
====================

Project Title:
Personal Landing Page

Author:
Emmanuel Levinne Tecson

Description:
This project is a responsive landing page designed to showcase a clean, modern,
and user-friendly interface. It serves as an introductory page for a personal
portfolio, product, or service. The landing page focuses on visual appeal,
clarity of content, and smooth user experience across different devices.

Features:
- Clean and modern UI design
- Fully responsive layout (desktop, tablet, and mobile)
- Organized sections (Hero, About, Services/Features, Contact)
- Custom styling using CSS
- Easy-to-read typography and layout
- Fast loading and lightweight structure

Technologies Used:
- HTML5
- CSS3
- JavaScript for interactivity

File Structure:
- index.html        -> Main landing page file
- css/
  - style.css       -> Main stylesheet
- assets/
  - images/         -> Images and icons used in the page
- README.txt        -> Project documentation

How to Run the Project:
1. Download or extract the project files.
2. Open the folder.
3. Double-click on `index.html` or open it using any modern web browser
   (Google Chrome, Microsoft Edge, Firefox, etc.).

Purpose:
This landing page was created for educational and portfolio purposes. It
demonstrates front-end web development skills including layout design,
responsiveness, and visual styling.

Notes:
- No external libraries are required.
- Internet connection is not required unless external fonts or assets are used.
- The design can be customized easily by editing the CSS file.
